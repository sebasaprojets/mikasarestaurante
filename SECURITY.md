# Política de segurança

Encontrou uma vulnerabilidade no site do MIKASA? Por favor, **não abra uma issue pública**.
Use o *Private vulnerability reporting* do GitHub (aba **Security → Report a vulnerability**) deste repositório.

Inclua os passos para reproduzir e o impacto. Responderemos o quanto antes.
Testes devem ser não destrutivos: sem negação de serviço, sem engenharia social e sem acesso a dados de terceiros.

Detalhes técnicos, controles e riscos conhecidos: [`docs/SECURITY.md`](docs/SECURITY.md).
